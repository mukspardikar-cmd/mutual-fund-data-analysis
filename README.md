# Mutual Fund Data Analysis

## Project Overview

This project focuses on analyzing mutual fund data to organize fund information, explore key metrics, and identify funds based on selected criteria. Python is used for data analysis, while Power BI is used to create an interactive dashboard.

## Tools & Technologies

* **Python** — Data analysis and processing
* **Pandas & NumPy** — Data manipulation
* **Matplotlib** — Data visualization
* **Microsoft Power BI** — Dashboard and visual reporting
* **Microsoft Excel** — Tabular output and reporting

## Project Workflow

1. Loaded and explored the mutual fund dataset.
2. Cleaned and prepared the data for analysis.
3. Analyzed the available fund information.
4. Created charts to visualize the data.
5. Exported processed data and selected fund information.
6. Developed a Power BI dashboard to present the analysis.

## Project Structure

* `data/` — Cleaned dataset
* `charts/` — Data visualizations
* `output/` — Excel analysis output
* `powerbi/` — Power BI project file
* `mutual_fund_project.py` — Python analysis script
* `comprehensive_mutual_funds_data.csv` — Source dataset

## Project Files

The repository includes the Python analysis script, dataset files, generated charts, an Excel output file, and a Power BI dashboard file.

## How to Explore

1. Review the Python script to understand the analysis workflow.
2. Open the charts to explore the visualizations.
3. Open the Excel output file to review the exported results.
4. Open the `.pbix` file using Microsoft Power BI Desktop to explore the dashboard.

## Objective

To practice data cleaning, exploratory data analysis, visualization, and dashboard development using a mutual fund dataset.
